Ihre Antworten und Ergebnisse

Alles, was Sie im Test antworten, bleibt nur auf Ihrem Gerät. Die App speichert Ihre Antworten, Ergebnisse, den gemerkten Erlaubnis-Satz und die 7-Tage-Übung im Speicher der App. Nichts davon wird an uns oder an andere gesendet. Wir können Ihre Ergebnisse nicht sehen.

Löschen: Entfernen Sie die App vom Gerät. In der Web-Fassung löschen Sie die Website-Daten im Browser. Danach ist alles weg.

Wann die App ins Internet geht

Die App läuft auch ohne Internet. Nur in diesen Fällen wird eine Verbindung aufgebaut:

  • Suche nach Neuerungen: Die Android-App fragt beim Öffnen, höchstens alle sechs Stunden, bei GitHub nach, ob es eine neue Version gibt. Dabei erhält GitHub technisch bedingt Ihre IP-Adresse. Es werden keine Angaben zu Ihnen oder Ihren Antworten übertragen.
  • Web-Fassung: Wird die App im Browser geöffnet, liefert GitHub Pages die Dateien aus. Auch dabei sieht GitHub Ihre IP-Adresse.
  • Links: Tippen Sie auf das MAYOKA-Logo oder auf die Quelle (doi.org), öffnet sich die jeweilige Website in Ihrem Browser. Dort gelten deren Datenschutz-Regeln.

GitHub wird betrieben von GitHub, Inc., USA. Datenschutz bei GitHub: docs.github.com. GitHub ist nach dem EU-US-Datenschutzrahmen zertifiziert.

Ergebnis teilen

Nur wenn Sie auf „Ergebnis teilen“ tippen, übergibt die App den Ergebnis-Text an die App, die Sie dann auswählen (zum Beispiel eine Nachrichten-App). Was dort passiert, liegt bei dieser App.
